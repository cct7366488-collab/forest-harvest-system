# 全國森林資源調查樣區資料

## 資料定位

本資料夾存放 Forest Harvest System 開發過程中使用之全臺灣森林資源調查樣區原始資料。

## 資料集

### 第三次森林資源調查

- 檔案：data/raw/nfi/nfi3/第三次森林資源調查樣區.7z
- 性質：全臺灣第三次森林資源調查樣區資料
- 用途：作為歷史樣區資料、立木材積模式、收穫表、生長模式與樣區資料結構設計之參考。

### 第四次森林資源調查

- 檔案：data/raw/nfi/nfi4/第四次森林資源調查Final_20250505.7z
- 性質：全臺灣第四次森林資源調查樣區資料
- 用途：作為第四次森林資源調查樣區資料、後續立木材積式、收穫表、生長量分析與森林碳匯模型建構之參考。

## 資料管理原則

1. data/raw/nfi 只存放原始資料。
2. 原始資料不直接修改。
3. 清理後資料應另存於 data/processed/nfi。
4. 建模資料表應另存於 database 或由 PostgreSQL/PostGIS 管理。
5. 大型原始資料原則上不直接推送到 GitHub，避免 repository 過大。

## 未來資料庫設計用途

本資料將支援下列資料表與模型設計：

- plots：樣區基本資料表
- trees：樣木資料表
- species：樹種代碼表
- volume_models：立木材積式資料表
- height_models：樹高曲線式資料表
- yield_tables：收穫表資料表
- nfi_cycles：森林資源調查期別表
- nfi_plot_remeasurement：複查樣區時間序列資料表

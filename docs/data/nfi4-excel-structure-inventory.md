## 三、初步判讀方向

若 Excel 中存在 DBH、胸徑、樹種、樣木號、樹高等欄位，則該 Excel 可能包含真正樣木資料。

若 Excel 只包含 Height、Volumn、Crown、樣區BA、樣區Vol、CO2_ha 等欄位，則較可能仍為樣區或林分層級資料。

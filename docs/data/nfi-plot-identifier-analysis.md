## 二、後續判斷原則

1. 若有非空且唯一的欄位，優先作為 `original_plot_id`。
2. `plot_code` 建議加上調查期別前綴，例如 `NFI4-xxxxx`。
3. 若單一欄位不唯一，應考慮組合欄位，例如 `SampleID + BlockID + X_Coord + Y_Coord`。
4. NFI3 / NFI4 是否可重測比對，需另行確認是否存在共同樣區識別碼或空間鄰近關係。

1. 依本報告選定 NFI3 / NFI4 的正式唯一識別欄位。
2. 修正 `nfi-field-mapping.json`。

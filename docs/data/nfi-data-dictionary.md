# NFI3 / NFI4 資料字典

產生時間：2026-05-10 14:57:32

## 一、文件目的

本文件依據 NFI3 與 NFI4 森林資源調查樣區 Shapefile 欄位結構，自動建立資料字典初版。

本資料字典將作為 Forest Harvest System 後續資料庫設計、資料匯入、欄位對應與模型建構之基礎。

## 二、資料表設計用途

本資料字典將支援下列資料表設計：

- `plots`：樣區基本資料表
- `trees`：樣木資料表
- `species`：樹種代碼表
- `volume_models`：立木材積式資料表
- `height_models`：樹高曲線式資料表
- `nfi_cycles`：森林資源調查期別表
- `nfi_plot_remeasurement`：樣區重測關聯表

## 四、欄位分類說明

### 1. 識別與編碼欄位

包含樣區代碼、調查期別代碼、樹種代碼、資料識別碼等。

### 2. 空間定位欄位

包含座標、經緯度、TWD97 / TM2 座標、幾何資訊等。

### 3. 環境與林分欄位

包含海拔、坡度、坡向、土地利用、林型、林分狀態等。

### 4. 樣木與林木量測欄位

包含樹種、胸徑、樹高、枝下高、材積、生長量等。

### 5. 調查時間欄位

包含調查日期、年度、調查期別等。
